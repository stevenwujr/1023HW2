這是古典回歸理論中非常經典的考點，以下是完整的矩陣數學推導：

假設多元線性回歸模型為：y = Xβ + ε，其中誤差項 ε ~ N(0, σ²I)。最小二乘估計量為 β̂ = (XᵀX)⁻¹Xᵀy，殘差變異數估計為 s² = MSE = SSE / (n - p - 1)。

當給定一組新的特徵向量 x₀ = [1, x₀₁, x₀₂, ..., x₀ₚ]ᵀ，點預測值為 ŷ₀ = x₀ᵀβ̂。

1. 95% 信賴區間 (Confidence Interval for Mean Response, E[y₀|x₀])：

信賴區間衡量的是母體平均值估計的不確定性。因為 Var(ŷ₀) = Var(x₀ᵀβ̂) = x₀ᵀ Var(β̂) x₀ = s² · x₀ᵀ(XᵀX)⁻¹x₀。

SE_mean(x₀) = s · √(x₀ᵀ (XᵀX)⁻¹ x₀)
CI_95% = ŷ₀ ± t_{0.025, n-p-1} · SE_mean(x₀)

特性： 當樣本數 n 趨近無限大時，(XᵀX)⁻¹ 趨近於 0，因此 CI 的寬度會收斂縮小為 0。

2. 95% 預測區間 (Prediction Interval for Individual Observation, y₀)：

預測區間預測的是單一全新觀測值 y₀ = x₀ᵀβ + ε₀。此時的不確定性包含兩部分：參數估計的不確定性 Var(ŷ₀) 以及該新樣本本身的隨機波動 Var(ε₀) = σ²。

Var(y₀ - ŷ₀) = Var(ŷ₀) + Var(ε₀) = s² · [1 + x₀ᵀ(XᵀX)⁻¹x₀]
SE_pred(x₀) = s · √(1 + x₀ᵀ (XᵀX)⁻¹ x₀)
PI_95% = ŷ₀ ± t_{0.025, n-p-1} · SE_pred(x₀)

特性： 預測區間永遠比信賴區間更寬！因為即使 n 趨近無限大，仍保有 s · √1 = s 的誤差波動，區間寬度至少為 ± 2s。

在古典多元線性回歸 (Gauss-Markov 定理) 中，必須依序檢驗以下五大假設：

  1. 線性性 (Linearity)： 特徵與目標呈線性關係。以 Residuals vs. Fitted 散佈圖 檢驗，殘差應隨機均勻分佈在 e = 0 兩側，無拋物線或彎曲趨勢。
  2. 常態性 (Normality of Residuals)： 誤差項服從常態分佈。繪製 Normal Q-Q Plot，標準化殘差分位數應貼齊 45 度對角線。
  3. 同質變異性 (Homoscedasticity)： 誤差變異數齊一。以 Scale-Location 圖 (√|Standardized Residuals| vs. Fitted) 檢驗，散布帶寬應維持平行穩定，無漏斗形發散。
  4. 獨立性 (Independence)： 觀測樣本誤差項互不相關。使用 Durbin-Watson 統計量 檢定：d = Σ(eᵢ - eᵢ₋₁)² / Σ eᵢ²。數值介於 1.8 至 2.2 表無自相關，完全滿足獨立性。
  5. 無多重共線性 (No Multicollinearity)： 輸入特徵之間無高度線性相依。計算每一特徵之 變異數膨脹因子 (VIF = 1 / (1 - Rⱼ²))。VIF < 5 為極佳，< 10 為可接受。
